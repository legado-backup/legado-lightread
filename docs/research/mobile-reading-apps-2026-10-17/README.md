## 建议体验顺序

1. 打开原型，点《山间来信》的“继续阅读”。左右滑动翻页；轻点中间呼出工具。
2. 打开“排版”，试字号、宋体/文楷、配色、翻页/连续滚动。切换后保留文本位置附近。
3. 打开“模式”，分别试夜读、护眼、大字、自动阅读、打字机和歌词；可暂停或退出。
4. 点“听书”，体验播放、语速、定时、目录、收起和返回原文。默认是明确标记的无声节奏演示；在“系统语音”里关掉节奏演示后，使用设备可用的真实声音。
5. 选中文字写笔记，返回藏书导入一份 TXT；刷新确认数据仍在。
6. 设置 → 账号与同步可体验演示连接、同步过程与偏好。设置 → 关于 → 可验证的状态可直接进入失败、待补文件、定时结束等状态。

## 运行边界

原型面向现代浏览器，数据保存在本文件独立的浏览器存储中，换域名或换浏览器不会自动迁移。账号/WebDAV/在线 AI/在线与离线音色安装/远程书源/互传是明确标注的流程演示；不连接真实服务、不发送密码或密钥。系统语音与屏幕常亮取决于浏览器支持。论文使用原创 HTML 样稿，完整 EPUB/PDF 引擎不包含在这份单文件中。

应用源码和原有 reader-panels-v2.html 均未改动。只新增本目录及 lightread-mobile-v3.html。

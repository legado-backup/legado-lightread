# 原型功能与验收

原型文件：[lightread-mobile-v3.html](../../prototypes/lightread-mobile-v3.html)。本文件的“可运行”指独立 HTML 内实际执行的行为，不代表已接入轻阅应用后端。

## 可运行功能

| 模块 | 实际行为 |
|---|---|
| 藏书 | 搜索、筛选、排序、网格/列表、书单、标签、私密标记、读完标记、多选、删除与撤销 |
| 文件 | TXT/Markdown/HTML 多文件导入；按章节标题拆分；HTML 提取文字，移除脚本与嵌入内容；JSON 原型备份导入导出 |
| 阅读 | 左右分页、按章滚动、跨章连续滚动、章节跳转、进度条、书内搜索、位置保存；宽屏双栏、手机单栏 |
| 排版 | 字号、字距、行距、边距、缩进、对齐；黑体/宋体/文楷嵌入字形与本地字体导入；五种配色、书页调暗 |
| 场景 | 夜读、护眼、大字、墨水屏、沉浸；临时覆盖参数，退出恢复原偏好；夜间面板与工具一起变暗 |
| 带读 | 自动翻页/滚动、打字机逐字/逐句/逐段、歌词按句聚焦；速度、暂停/继续、退出、互斥切换 |
| 笔记 | 选区复制、划线、想法；书签、跳回正文、修改/删除/导出；刷新保留 |
| 听书 | 无声节奏按句推进；可用时真实调用系统语音；播放/暂停、前后句/段、章节进度、目录、速度、定时到点停止、本章结束停止、再听15分钟 |
| 听读衔接 | 完整播放器/迷你条、独立听书位置、返回原文、改听当前页、歌词跟随、错误恢复 |
| 背景音 | Web Audio 合成雨声/风声/底噪/和声，音量、定时和听书时压低；不是录制自然音 |
| 论文 | 原创 HTML 样稿，原版/重排、目录、缩略图、页码、缩放、选中复制、想法与书签回看 |
| 阅读记录 | 当前原型中的阅读秒数累计、周/月/年/全部、当月日历、目标与继续阅读入口；不展示虚构历史数据 |
| 设置 | 浅色/深色/跟随系统、阅读偏好、功能开关、配置表单验证、本地偏好保存、重置原型 |

原型中“智能点睛”为预置词组强调；歌词按句聚焦，不等同于应用底层的精确视觉行算法。字体为嵌入的字符子集，导入文本中未包含的字符由系统字体补齐。导入字体仅在当前打开会话有效，刷新回退黑体并保留其余设置。

## 明确标记的流程演示

| 流程 | 可以验证 | 不实际执行 |
|---|---|---|
| 账号/WebDAV | 必填与地址校验、连接中、成功、失败重试、同步阶段、文件待补、开关、密码密钥确认、断开 | 真实登录、联网认证、上传或下载 |
| 音色 | 系统音色可试听；在线音色选择、离线包安装/就绪状态 | 在线合成、离线模型下载 |
| 书源 | 搜索范围保留、样章结果、无结果/错误重试、添加到藏书、私人书库表单 | 远程书源请求与凭据存储 |
| AI/翻译 | 配置表单、预置回答、原文译文对照、复制 | 在线推理或真实文档分析 |
| 互传 | 取件码有效/过期、样章保存、文字/链接/文件取件码、撤回 | 跨设备联网、真实文件上传 |
| PDF/EPUB | 论文与文字样章用于验证阅读流程 | 完整格式解析与真实 PDF 批注引擎 |

所有服务依赖的成功反馈都处于明确标识的演示页面内。通用设置和阅读设置分别管理界面外观与正文主题。

## 检查结果

55 项行为断言通过，已遍历面板未发现未接线动作或页面报错；指定宽度下未发现横向溢出。K30 实机首屏宽度 392 CSS px，藏书、正文、排版均可打开。结果摘要见 [summary.json](prototype-qa/summary.json)，画面见[验收截图画廊](prototype-qa/gallery.html)。

## 检查方法

- Playwright 使用用户实际点击/输入完成阅读、排版、笔记、书单、删除撤销、听书、同步与导入流程；测试状态钩子只用于导航、枚举面板和将定时器移到临近到点。
- 遍历声明的面板并核对动作处理器；检查主导航、二级设置及不同宽度的溢出。宽度为 320、375、414、768、1440 CSS px。
- 在 K30 的实际 Android Edge 浏览器载入同一 HTML，验证藏书、正文与排版面板。通过 DevTools 注入本地响应传输文件，画面截图仍由设备原生 screencap 取得，未制作手机外框。
- 系统语音检查包含无可用音色时的错误恢复，不宣称所有系统语音服务、长时间后台或锁屏均已通过。

具体断言与结果见 [checks.json](prototype-qa/checks.json)、[extended-checks.json](prototype-qa/extended-checks.json)，实机记录见 [k30-checks.json](prototype-qa/k30-checks.json)。截图位于 [prototype-qa](prototype-qa/)；竞品原始截图单独保存在 screenshots，不混为原型验收证据。

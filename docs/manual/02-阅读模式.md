# 二、阅读模式与阅读界面

这一篇讲两件事：

1. **阅读模式**：让书「自己往前走」的两种方式——**自动翻页**和**打字机**。
2. **阅读界面**：主题、字体、字号、翻页 / 滚动、进度显示、沉浸式工具栏、全屏、跳页等「怎么把书摆得舒服」的设置。

> 本篇说的是 EPUB、MOBI、AZW3、FB2、TXT、HTML、Markdown 等**流式电子书**的阅读页。PDF 和论文有单独的阅读页，见 [04-使用说明](04-使用说明.md#6-pdf-与论文阅读)。

---

## 1. 打开「阅读模式」面板

| 设备 | 入口 |
|---|---|
| 电脑（窗口较宽时） | 阅读页**顶栏**的「阅读模式」图标按钮 |
| 手机（或窗口宽度 ≤ 600px） | 点屏幕中间呼出工具栏，**底栏**第四个按钮「模式」 |
| 键盘 | 按 **M** |

面板顶部有两个分页：**自动翻页** 和 **打字机**。电脑上面板浮在顶栏下方，手机上是从底部弹出的抽屉，点遮罩即可收起。

正在使用某个模式时，入口按钮会高亮。同一时间只能打开一个面板，打开「阅读模式」会自动收起目录、排版等其他面板。

---

## 2. 自动翻页

每隔设定的秒数自动翻到下一页，适合双手不方便、或想保持匀速阅读的时候。

**怎么用**

1. 打开「阅读模式」面板，切到「自动翻页」。
2. 拖动「速度」滑块，范围 **3–60 秒/页**（默认 15 秒/页）。
3. 点「开始」。再次打开面板点「暂停」即可停下。

**要知道的**

- 翻到全书最后会自动停止。
- 按 **Esc** 也会停止自动翻页。
- 自动翻页和打字机、听书互斥：开始打字机会停止自动翻页，并提示「已停止自动翻页」。
- 调整速度后立即按新速度继续。

## 3. 打字机模式

打字机模式会把**当前页**的文字隐藏起来，再按你设定的速度一个字一个字（或一句一句、一行一行）地「打」出来。读过的文字始终可见，打完一页会稍作停留再自动翻页。

它的作用是**用节奏帮你进入状态**、减少走神，并不承诺让你读得更快——面板上也是这么写的。

### 3.1 开始与退出

1. 打开「阅读模式」面板，切到「打字机」。
2. 按需调整下面的选项。
3. 点「**从本页开始**」。面板会自动收起，文字从当前页开头开始出现。
4. 想结束时，打开面板点「**退出打字机**」，或按 **Shift+T** / **Esc**。

> 也可以不开面板，直接按 **Shift+T** 开始或退出。

### 3.2 选项说明

| 选项 | 可选值 | 说明 |
|---|---|---|
| **粒度** | 逐字 / 逐句 / 逐行 | 文字出现的单位。默认「逐字」；逐句、逐行画面跳动更少 |
| **速度** | 中文 60–1200 字/分；西文 40–800 词/分 | 默认中文 300 字/分、西文 200 词/分。单位按书的语言自动切换 |
| **快捷档** | 慢 / 中 / 快 | 中文书为 200 / 300 / 450 字/分；西文书为 150 / 200 / 300 词/分 |
| **后文** | 隐藏 / 淡显 | 还没「打到」的文字是完全隐藏，还是用很淡的颜色先显示出来 |
| **标点停顿** | 开 / 关 | 遇到句号、逗号等标点时稍作停顿，更接近自然阅读节奏（默认开） |
| **墨迹未干** | 开 / 关 | 刚出现的几个字用强调色显示，帮助视线跟上（默认开） |
| **打字声** | 开 / 关 | 出字时播放轻微的打字声（默认关）。速度超过 600 字/分时每 3 个字响一次；听书进行中时不发声 |

**调速度的三种方法**

- 拖动滑块，或点两侧的「减速」「加速」按钮（每次约 ±10%）。
- 点「慢 / 中 / 快」快捷档。
- **直接输入数字**：在滑块右边的数字框里输入想要的速度，按回车或点别处生效。超出范围时会自动收到最接近的有效值，并在框里显示实际生效的数字。

### 3.3 运行中的操作

| 想做什么 | 怎么做 |
|---|---|
| 暂停 / 继续 | **轻点正文任意位置**（打字机运行时轻点不会翻页，防止误触）；或按 **空格**；或点底部迷你控制条的按钮 |
| 当前段直接显示完 | 按 **→** |
| 重新打当前这句 | 按 **←** |
| 加速 / 减速 | **Shift+↑** / **Shift+↓**，或迷你控制条上的 − / + |
| 退出 | **Esc**、**Shift+T**，或迷你控制条上的退出按钮 |
| 想仔细看某句 | 长按选中文字：打字机会暂停，并把进度推进到你选中的地方 |

**底部迷你控制条**：打字机运行时，屏幕底部居中会出现一条小控制条，显示状态（打字中 / 已暂停 / 即将翻页）、当前速度和本章大约还要多久，以及暂停、减速、加速、退出按钮。运行 3 秒后它会自动淡出，暂停时一直显示；呼出工具栏时它会让到底栏上方。

**会自动暂停的情况**：打开任何面板（目录、排版、阅读模式等）、切到其他应用或窗口进入后台时，打字机都会自动暂停，回来后点一下即可继续。

### 3.4 进度与剩余时间

打字机运行时，再打开「阅读模式」面板，顶部会显示：

- 当前章名和本章进度条；
- **本章还剩约多久**；
- **预计几点读完**本章（跨过午夜会显示「预计明天 …」）；
- **全书百分比**和全书大约还剩多久。

这些时间是按你设定的速度估算的（开了「标点停顿」会多留一点余量），并随时间自动刷新。迷你控制条上也会显示「本章约 N 分钟」。

### 3.5 和其他功能的关系

- **与听书、自动翻页互斥**：开始打字机会停止自动翻页、暂停听书；反过来开始听书或自动翻页时，打字机会自动退出并提示「已退出打字机模式」。
- **阅读时长照常记录**：打字机推进算作阅读，计入「阅读记录」。
- **不支持固定版式的书**：漫画、按页排版的 EPUB 等会提示「固定版式的书暂不支持打字机模式」。PDF 也没有打字机模式。
- **系统开启了「减少动态效果」**：面板会提示建议使用逐句显示，翻页前也会多停一会儿；第一次使用时默认粒度会自动改为「逐句」。

### 3.6 键盘快捷键一览

| 按键 | 作用 | 何时有效 |
|---|---|---|
| **M** | 打开 / 关闭「阅读模式」面板 | 阅读页任何时候 |
| **Shift+T** | 开始 / 退出打字机 | 阅读页任何时候 |
| **空格** | 暂停 / 继续 | 打字机运行中 |
| **→** | 当前段直接显示到段末 | 打字机运行中 |
| **←** | 重打当前这一句 | 打字机运行中 |
| **Shift+↑ / Shift+↓** | 加速 / 减速 | 打字机运行中 |
| **Esc** | 退出打字机并关闭面板；面板开着而打字机没在运行时，只关闭面板 | — |

在搜索框、跳页框等输入框里打字时，这些快捷键不生效。打字机没在运行时，空格和左右方向键仍是普通的翻页键。

## 4. 把书摆得舒服：阅读界面设置

### 4.1 排版面板

打开方式：电脑点顶栏「排版设置」图标；手机点底栏「排版」。

| 设置 | 范围 / 选项 | 说明 |
|---|---|---|
| **字号** | 滑块 12–64，数字框可输入 | 也可点「A−」「A+」逐级调整 |
| **行距** | 1.2–2.6 | 默认 1.8 |
| **边距** | 2%–16% | 页面左右留白，默认 6% |
| **字体** | 默认 / 宋体 / 黑体 / 楷体，以及系统字体、自定义字体 | 桌面版可点「＋ 导入字体文件」导入 ttf / otf / woff2 |
| **主题** | 五个色块 | 见下表 |
| **模式** | 翻页 / 滚动 | 翻页像纸书一页一页；滚动是整章上下连续滑动 |
| **分栏** | 单栏 / 自动双栏 | 自动双栏在宽屏时显示两栏，窄屏仍为一栏 |
| **进度** | 页码+百分比 / 页码 / 百分比 | 控制页脚和底栏显示哪种进度 |

这些设置**对所有书籍生效**。想一键还原，到「设置 → 阅读偏好 → 恢复默认排版」。

### 4.2 正文主题

排版面板里的「主题」是五个色块，每个色块上写着一个「文」字，直接预览底色和文字颜色：

| 色块 | 效果 |
|---|---|
| 白底黑字 | 浅色 |
| 米黄底 | 类似旧纸张，暖色调 |
| 浅绿底 | 护眼绿 |
| 深灰底浅色字 | 夜间 |
| 斜切的半白半黑色块（悬停提示「跟随外观」） | **默认**。跟随应用外观：浅色外观时用白底，深色外观时用夜间 |

> 正文主题和应用外观是两个独立的设置。应用外观在「设置 → 通用 → 外观」（跟随系统 / 浅色 / 深色）里改，它决定书架、设置等界面的配色。如果你在阅读页明确选了某个主题（比如米黄），它就不会再跟着外观变化；只有「跟随外观」会自动切换。

### 4.3 翻页的方法

- **点屏幕**：点左侧三分之一翻到上一页，右侧三分之一翻到下一页，**中间三分之一**呼出或隐藏工具栏。点到页面最上沿、最下沿（章名、页码那条带）也按同样的左 / 中 / 右分区处理。
- **滑动**：触屏左右滑动翻页；翻页模式下上下滑动也能翻页。滚动模式下滑到本章末尾后继续上滑，就进入下一章。
- **键盘**：**←** / **PageUp** 上一页；**→** / **PageDown** / **空格** 下一页。
- **按钮**：鼠标移到阅读区时，左右两侧会出现上一页 / 下一页按钮。
- **章节**：底栏进度条两端的按钮是「上一章」「下一章」。

### 4.4 沉浸式工具栏

阅读页的顶栏和底栏是浮在正文上的，正文始终占满整个窗口：

- 翻页时工具栏自动隐藏，只剩正文。
- 点屏幕中间，或把鼠标移到窗口最上 / 最下边缘，工具栏重新出现。
- 打开任何面板时工具栏不会自动收起。

**顶栏**（电脑）从左到右：返回藏书、书名与当前章、目录、标注与书签、书签、听书、AI 助手、书内搜索、阅读模式、排版设置、全屏阅读。手机上顶栏只保留返回、书签、AI 助手和书内搜索，其余放到底栏：**目录 / 笔记 / 听书 / 模式 / 排版**。

### 4.5 全屏

- 电脑点顶栏最右的「全屏阅读」。进入全屏后工具栏会自动隐去，直接进入纯文字状态。
- 全屏且工具栏隐藏时，右上角有一个悬浮的「退出全屏」按钮；也可以按 **Esc** 退出。
- 手机上没有全屏按钮，隐藏工具栏后就是满屏阅读。

### 4.6 进度显示与跳页

- **页脚**：页面上方显示章名，下方显示进度（按排版面板「进度」的选择显示页码、百分比或两者），并提示「本章剩 N 页」或「本章最后一页」。
- **进度条**：拖动底栏进度条时，会在气泡里预览将要到达的章节和位置，松手才跳转。
- **跳到指定位置**：点底栏右侧的页码 / 百分比，弹出跳转框，输入**页码**（如 `120`）或**百分比**（如 `35%`），点「跳转」。如果这本书带有纸书页码，跳转框里还会显示「纸书第 N 页」。
- **跳回原处**：通过进度条、跳转框、目录等跳走后，底部会出现「回到第 N 页」按钮（约 12 秒内有效），点一下回到跳转前的位置。

> 页码是按当前字号、行距和屏幕大小实时计算的，改了排版或换了设备，页数会随之变化——跳转框里也有这条提示。百分比则始终不变。

## 5. 即将推出

以下模式**正在规划中，尚未上线**，具体形式和上线时间以后续版本为准：

- **歌词**：像歌词一样，当前行居中聚焦，自动向前滚动。
- **大字**：面向长辈和需要大字号的读者的一键阅读模式。
- **墨水屏**：适合墨水屏设备的黑白、少动画显示。
- **点睛阅读**：由 AI 预读全书，帮你点出书中的关键概念与要点。
- **仿生阅读**：通过强调词首等排版方式引导视线，计划以实验功能提供。

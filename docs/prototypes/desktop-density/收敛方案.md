# 轻阅样式收敛方案（草案，2026-10-26）

> 目的：解决"局部改好了，整体不协调"和"桌面元素太密、文案太多"。
> 状态：待选原型风格。档位确定后再改 `src/styles/main.css`，并逐页替换。

## 1. 现状（2026-10-26 统计 `src/**/*.vue|css`）

| 属性 | 不同取值 | 使用处 | 其中用了令牌 | 典型乱象 |
|---|---|---|---|---|
| 字号 `font-size` | **46** | 1221 | **17（1.4%）** | 10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 … 都有 |
| 字重 `font-weight` | 8 | 380 | — | 500 / 550 / 560 / 600 / 650 / 700 混用 |
| 圆角 `border-radius` | **39** | 768 | 368（48%） | 1–12px 的每个整数都出现过 |
| 阴影 `box-shadow` | **64** | 350 | 201（57%） | 封面、按钮、卡片各写各的 |
| 间距 `gap` | — | 983 | **40（4%）** | 6 / 10 / 14 / 18 等非档位值 |
| 内边距 `padding` | **269** | — | — | — |

单文件字号最多的：`PaperReaderView`（桌面 / 手机各 16 种）、`SettingsView`（14）、`TodayCard`（14）、`CatalogView`（12）。

**根因**：`main.css` 已经定义了 `--fs-* / --space-* / --radius* / --shadow*`，但组件几乎都直接写 px。每次局部修改都会顺手加一个"这里看着刚好"的新值，单看都对，合起来就互相打架。

## 2. 收敛档位

原则：**档位少到不用想就能选对**。阅读正文字号、排版由用户设置决定，不在此列。

### 2.1 字号：6 档（语义命名，桌面 / 手机两套取值）

| 令牌 | 桌面 | 手机 | 用途 | 现有值并入 |
|---|---|---|---|---|
| `--fs-caption` | 12 | 12 | 角标、时间、辅助数字 | 10, 10.5, 11, 11.5, 12 |
| `--fs-small` | 13 | 13 | 次要文字、作者、说明 | 12.5, 13 |
| `--fs-body` | 14 | 15 | 正文、按钮、列表主文字 | 13.5, 14, 15 |
| `--fs-subtitle` | 16 | 17 | 卡片标题、分组标题 | 16, 17, 18 |
| `--fs-title` | 20 | 22 | 弹窗标题、二级页标题 | 19, 20, 22, 24 |
| `--fs-display` | 28 | 28 | 页面大标题、大数字 | 26, 28, 32 |

字重只保留 **400 / 500 / 600**（550、560、650、700 → 600）。

### 2.2 间距：沿用现有 `--space-*`，补一档

`4 · 8 · 12 · 16 · 24 · 32 · 48`（`--space-1/2/3/4/6/8/12`）。`--space-5`（20）和 `--space-10`（40）只做过渡，逐步替换掉。6 → 8，10 → 8 或 12，14 → 12 或 16，18 → 16 或 24。

规则：**组内间距 < 组间间距**，至少差一档。

### 2.3 圆角：4 档 + 胶囊

| 令牌 | 值 | 用途 |
|---|---|---|
| `--radius-xs` | 4 | 书封、小标签、进度条 |
| `--radius-sm` | 8 | 按钮、输入框、菜单项、列表行 |
| `--radius` | 12 | 卡片、面板、弹窗、浮层菜单 |
| `--radius-xl` | 20 | 只用于手机底部面板 |
| `--radius-pill` | 999 | 胶囊按钮、开关、头像 |

注意：现有 `--radius: 8px` 已被 368 处引用，改值会全局生效，要先逐处确认是"控件"还是"卡片"再分流到 `-sm` 或默认值。

### 2.4 阴影：3 档 + 焦点环

| 令牌 | 用途 |
|---|---|
| `--shadow-1` | 静止的卡片、书封 |
| `--shadow-2` | 悬停浮起 |
| `--shadow-3` | 浮层：菜单、弹窗、Toast |
| `--ring` | 键盘焦点 |

书封的书脊高光、描边属于"材质"，统一收进 `--cover-edge` / `--cover-shadow`，不再各写一份。

### 2.5 颜色

继续只用语义令牌。封面上的半透明黑底（`rgba(17,20,26,.6)` 等多处）统一成 `--scrim` / `--scrim-strong`。`PaperReaderView` 的约 20 处硬编码色值单独处理（已知问题）。

## 3. 密度与文案规则（桌面）

1. **页面标题下不放说明句。**说明放进空状态、首次引导或悬停提示。（现状：藏书、书源、设置各节都有。）
2. **一个视图只有一个主按钮。**其它操作用次级按钮或收进「⋯」。
3. **工具栏一行最多：**搜索 + 一个排序/视图控件 + 主按钮。「管理」改成选择模式入口（「⋯」或 ⌘/Shift 点选）。
4. **书卡 = 封面 + 书名一行 + 一行元信息。**
   - 封面上不常驻任何标签。格式、私密、大小进列表视图或「详情」。
   - 悬停只出现一个「⋯」，点开是菜单；不再竖排 5–6 个图标按钮。
   - 书名用 `shortTitle()`（与手机一致），完整书名放悬停提示。
   - "佚名"不显示：没有作者就只显示进度。
5. **设置项一行一件事：**左边标签、右边控件。说明只在"不说就会出错或有风险"时出现，最多一行。
6. **书单不单独占一张卡片**，并入藏书的筛选（全部 / 在读 / 读完 / 书单 ▾）。

## 4. 执行步骤

1. **选风格**：在 `index.html` 里比较 A–D 四个原型，选一个（或指定组合）。
2. **改令牌**：按 §2 改 `main.css`，新令牌和旧令牌并存一段时间（旧名映射到新值）。
3. **加棘轮检查**：新增 `scripts/check-style-tokens.mjs`，统计裸 px 字号 / 圆角 / 阴影数量，CI 中**只许减少、不许增加**，防止再次发散。
4. **逐页替换**：桌面藏书 → 设置 → 书源 → 阅读记录 → 阅读器工具栏 → 论文；手机端随后（手机已改版页面只换令牌，不动布局）。
5. **每页验证**：t9 上跑 `npm run e2e` 和相关 e2e，并对照前后截图。

# 轻阅移动端交互原型 v4

- 原型：[../lightread-mobile-v4.html](../lightread-mobile-v4.html)（单文件约 1 MB，直接用浏览器打开，无需安装或启动应用）
- 截图索引：[index.html](index.html)（43 张流程截图 + 5 种宽度 × 2）
- 验收脚本与结果：[acceptance.mjs](acceptance.mjs)、[checks.json](checks.json)（51/51 通过）

本版本独立完成，没有修改 `src/`、应用样式、依赖、v3 原型或调研材料。存储键为 `lightread-proto-v4`（localStorage 与 IndexedDB），与 v3 的 `lightread-prototype-v3` 以及正式应用互不影响。

## 依据与证据口径

调研时查看了竞品实机截图：微信读书 07–21、30–45，京东读书 12、13、20、27、29。另外核对了轻阅源码中的真实能力：`stores/settings.ts`、`i18n/zh.ts` 中的听书、阅读模式和同步文案。最后才看 v3 的截图做对照。

| 类别 | 内容 |
|---|---|
| 直接观察 | 微信读书阅读工具栏为 5 个图标。面板停靠在工具栏上方，不加遮罩，正文在上方保持可见。「听」是独立的悬浮按钮。夜间主题下面板一起变暗。定时关闭有「本集结束后关闭」。电子书朗读的播放器结构与有声书一致。京东读书「原文」会回到正文并高亮当前句。 |
| 推断 | 不加遮罩的面板让「调一下、看一眼」连成一个动作，这正是微信读书排版顺手的主要原因。悬浮的「听」入口适合同时承担听书状态的显示。 |
| 我的设计决定 | 下文的布局、令牌和交互规则都是轻阅原型自己的选择，不是竞品源码令牌。色值参考了截图像素取样（浅冷灰底、白色分组、单一蓝色），次级文字已加深以保证对比度。 |

## 设计方案（与 v3 的主要差异及理由）

| 方面 | v3 | v4 | 理由 |
|---|---|---|---|
| 阅读面板 | 带遮罩的模态面板，排版分文字/配色/页面三个页签 | 底部 5 个入口：目录 · 笔记 · 模式 · 显示 · 文字。面板停靠在工具栏上方，**不加遮罩**，入口之间一点即切 | 调整时正文始终可见，可直接比较效果；少一层页签，常用项一屏放下 |
| 文字面板 | 三条滑杆 + 字体行 | 字号步进条（A− / 滑杆 / A+），边距和行距用「小中大」「紧中松」分段，字体/缩进/对齐用小标签。精确数值放在「更多排版」 | 学习微信读书「常用一眼可调，精细在下一层」 |
| 配色与翻页 | 分在不同页签 | 「显示」一处管调暗、配色、翻页、分栏、页脚进度。双栏不可用时写明原因，同时保留你的选择 | 这些都是「页面长什么样」，放在一起 |
| 阅读模式 | 场景图标 + 带读列表 | 顶部一行显示**当前组合**（如「夜读 + 大字 · 点睛 · 未在带读」）。每组写明规则：场景可叠加，但夜读/护眼/墨水屏三选一；点睛可与任何模式同时用；带读一次一个。运行时变成底部胶囊（状态 · 慢/快 · 暂停 · 设置 · 退出） | 用户能看到哪些在生效、为什么另一个被关掉 |
| 场景覆盖 | 临时覆盖 | 场景只覆盖生效值，不改保存的偏好。在大字场景里调字号，只存进大字场景，并提示退出后恢复的数值 | 对应源码 `largeText.custom` 与预设快照的思路 |
| 听书入口 | 播放器在独立位置 | 「听」悬浮钮常驻正文右下：未开始时显示「听」，听书中显示音波和「听书中 / 已暂停」 | 一个位置同时完成开始、状态和返回 |
| 听读位置 | 回到听书处 / 改听这一页 | 同样两个动作，但胶囊直接写出距离（「位置在后面第 2 页」「第三章 雨季」）和当前句开头。翻回听书处所在页时自动解除偏离 | 看得到距离，才好决定回去还是改听 |
| 播放器 | 独立浅色页面 | 播放器**跟随正文配色**：夜间时是深色，米黄时是米黄。分「播放 / 原文跟读」两栏，原文里点任意一句就从那句开始听。常用一行：定时 · 语音 · 语速 · 歌词 | 避免夜读时突然出现刺眼的白色播放器 |
| 状态规则 | — | 改语速或音色时保持原来的播放/暂停状态。定时按时钟计时，暂停也继续倒数，规则直接写在定时面板里。到点时停在当前句，并提供「再听 15 分钟」 | 规则说清楚，用户就不用猜 |
| 夜间一致性 | 夜间面板变暗 | 阅读器里的所有底部面板、对话框、胶囊和播放器都使用正文的配色令牌 | 同上 |
| 藏书 | 继续阅读卡 + 筛选 | 继续阅读卡在听书时显示「听书中 / 已暂停」，并直接给出「暂停 / 继续听」。标签并入筛选条；长按进入多选 | 听读状态一致地出现在首页 |

一级导航仍是藏书 · 论文 · 书源 · 阅读记录 · 设置（宽度 ≥960px 时改为左侧图标栏）。没有引入会员、金币、商城或运营任务。

### 视觉规格（原型设计决定）

- 应用：底色 `#F4F5F7`、卡片 `#FFF`、主文字 `#1F2329`、次级 `#4B525C`、弱信息 `#676E78`、品牌蓝 `#1670DA`（比取样的 `#1B88EE` 略深，为了白底上的文字对比度）。深色外观单独定义一套令牌。
- 正文配色：白 `#FBFBFC` · 米黄 `#F4EDDC` · 豆沙绿 `#E2EDDD` · 夜间 `#0F1012`（字 `#9EA2A8`）· 墨水屏纯黑白。每种配色同时定义面板色、强调色和高亮色。
- 正文默认 19px、行距 1.8、边距 24px、首行缩进、两端对齐。主要点击目标 ≥44px。处理了底部安全区，弹出键盘时面板随可视区上移。
- 字体：黑体用设备自带字体；宋体和文楷内嵌子集（思源宋体 Noto Serif CJK SC、霞鹜文楷，均为 SIL OFL 1.1）。子集是修改版本，所以内部字体名改为 `LR Song` / `LR Kai`，不使用保留字体名。许可证说明保留在 HTML 注释和「设置 → 关于」里。导入书里超出子集的字由设备字体补齐。

## 真实运行与流程演示的边界

**真实运行（在这个 HTML 里实际执行）**
- 导入 TXT / Markdown / HTML，按章节拆分，正文存进 IndexedDB；打开、翻页、保存位置；刷新后恢复。
- 左右翻页、按章滚动、跨章连续滚动（按需加载前后章节，加载时不跳动）、单栏 / 双栏、书内搜索、进度跳转与「回到跳转前」。
- 字体、字号、行距、字距、段距、边距、缩进、对齐、配色、调暗都真实作用于正文，调整后保持在当前句附近。
- 书签、划线、想法（选中文字）；回看与定位；修改、删除并撤销；导出 Markdown。
- 场景（夜读含定时开启、护眼含休息提醒、墨水屏、大字、沉浸）、点睛（预置词组，导入的书用简单词频）、自动翻页 / 自动滚动、打字机（逐字 / 逐句）、歌词（自动 / 跟听书 / 手动）。
- 听书：设备有系统语音时用 `speechSynthesis` 真实朗读；节奏演示（无声）按句推进；定时关闭到点真实停止；听完本章停止；迷你播放条。
- 阅读计时（只计本原型中的真实阅读和听书时间）、每日目标、日历；备份导出与导入；重置只影响 v4。

**流程演示（界面上有「流程演示 / 演示 / 预置」标识，不连接服务、不发送也不保存凭据）**
- 轻阅账号登录（演示验证码 246810）、WebDAV 连接、同步的各个阶段、失败与重试、待补文件。
- 在线语音、离线语音包下载：选中后无声推进，标签写着「无声」。
- 书源结果来自内置目录，「加入藏书」生成说明样章；私人书库连接；AI 助手配置与测试；论文翻译（预置译文）和论文助手（预置回答）；设备互传（取件码 482913 有效、000000 已过期）；从链接添加。
- 「设置 → 关于 → 演示状态」可以打开：下一次同步失败、下一次书源失败、下一次导入失败、模拟没有系统语音、制造待补文件、查看空书架。定时面板里另有「快进到还剩 10 秒」，方便验证到点停止。

论文为原创英文样稿，不是真实论文，不含实验数据。书籍样章与封面纹样均为原创。

## 验收结果

验收在 Playwright Chromium 中进行（390×844 移动视口，带触摸），全部用真实点击完成。`__v4` 钩子只用于读取状态和打开演示开关。结果见 [checks.json](checks.json)：**51/51 通过**，控制台无错误。覆盖以下流程：

- 导入 TXT → 阅读跨章 → 改字号、边距、宋体、米黄 → 刷新后再进入：位置和排版都恢复
- 选中文字 → 写想法 → 在笔记里回看并定位 → 删除 → 撤销
- 夜读 + 大字叠加；开护眼会关掉夜读；退出后恢复原配色和字号。自动翻页、打字机、歌词各自开始、暂停、继续、退出；歌词退出后恢复左右翻页
- 没有系统语音 → 说明与恢复入口 → 节奏演示（标注无声）→ 播放中改语速保持播放、暂停时改语速保持暂停 → 收起 → 手动翻页（听书位置不变，出现偏离提示）→ 回到听书处 → 改听这一页 → 定时 15 分钟、快进、到点停止 → 再听 15 分钟 → 迷你播放条暂停
- 同步：未配置 → 验证码错误 → 同步阶段 → 成功 → 失败 → 重试成功；同步密码与密钥需要单独确认，取消后保持关闭
- 论文助手标注预置回答；书源：结果 / 无结果 / 错误 → 重试；阅读记录来自真实计时；删除书籍可撤销；应用改为深色时不改变显式选择的正文配色；重置只清除 v4，保留 v3 存储
- 320 / 375 / 414 / 768 / 1440px：没有横向溢出，阅读工具全部可达

此外还做了一轮全按钮遍历：17 个页面中的每个可见按钮各点一次，没有报错。显示为「点击后无变化」的项逐一核对过：都是点了当前已选中的项，或者变化前后文本长度恰好相同（例如缩放从 100% 到 120%），没有未接线的入口。

**未验证 / 限制**
- **K30 实机未验收**：本次 `adb devices` 没有列出设备，连接 `127.0.0.1:15559` 被拒绝，所以没有在 Chrome 中打开，也没有实机截图。设备恢复后，把 HTML 推到 `/sdcard/Android/data/com.android.chrome/files/lightread-mobile-v4.html`，再用 `file:///` 路径打开即可。
- 无头浏览器里没有系统语音，所以验收走的是「没有可用语音 → 节奏演示」这条路径。真实朗读的代码已写好（按句朗读，6 秒无响应即报错），但需要在有中文语音的设备上试听确认。后台和锁屏播放没有验证。
- 「调整后保持在原段落附近」的断言是在章首页测的，较弱；在章中页的位置保持只做过人工检查。
- 安卓系统的长按选字菜单会和原型的选区工具条同时出现，这是浏览器行为，不是原型的缺陷。
- 没有设置在线预览。如果需要，请按现有的 Netlify 私有草稿约定另行上传。

划线一键复制 / 导出 · 原型

来自 issue #16。下方两块画板都能点：笔记面板底部的「复制全部」直接复制，「导出…」打开选项窗口，预览随选项实时变化。

用户原话

时常在读完书会将划线作为书摘放入个人笔记进行管理，希望增加该功能以便操作。参考微信读书（笔记面板底部「复制全部笔记 · 16」）。

真实需求

  • 读完一本书，把整本书的划线 + 想法一次带走，贴进 Obsidian / Notion / 备忘录
  • 贴过去要能直接用：有书名、作者、按章节分组、按书中顺序，划线和想法分得清
  • 一步完成：最常用的是「复制」，其次是「存成文件」

现状里的坑（先修再导出）

  • 划线原文入库时被截断：书 300 字、PDF 500 字，导出会拿到半句话
  • 不存章节，列表按划线时间排而不是书中顺序
  • 没有任何复制 / 导出入口（只有整库备份）

请确认的几件事

  1. 入口：笔记面板底部「复制全部 · N」+「导出…」，桌面和手机都放。建议另加藏书页书卡「⋯」→「导出笔记」，不打开书也能导（第二步做）。
  2. 格式：Markdown（默认，Obsidian / Notion 直接用）和纯文本（贴微信、备忘录）两种。以后可加 Readwise CSV、按书批量导出成一个文件夹。
  3. 「复制全部」默认用哪种格式：建议跟随上次在导出窗口里选的，首次为 Markdown。
  4. 内容：默认含章节标题和想法，不含时间；按书中位置排序；可按颜色筛选（面板上的颜色筛选会带进导出）。书签不导出。
  5. 截断修复：新划线存完整原文（上限放宽到约 5000 字）；旧的截断划线在书打开时按位置重新取全文并回写。新划线同时记下章节名，供不开书导出使用。
  6. 保存文件：桌面弹系统保存对话框（文件名《书名》笔记.md）；手机走系统分享 / 存到下载；网页版直接下载。

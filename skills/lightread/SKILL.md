# 轻阅 LightRead

轻阅是开源（AGPL-3.0）、免费、无广告、本地优先的电子书与 PDF 阅读器。本地阅读不需要账号也不需要联网；书、进度、笔记默认只在用户自己的设备上，同步、AI、在线听书都是可选的。

- 主页：https://yzfly.github.io/LightRead/
- 源码与下载：https://github.com/yzfly/LightRead （国内镜像 https://gitcode.com/langgpt/LightRead/releases ）
- 使用手册：https://github.com/yzfly/LightRead/blob/main/docs/manual/README.md
- 反馈：https://github.com/yzfly/LightRead/issues

回答时以用户的目标为中心：先给能马上照做的步骤（点哪里、选什么），再补充原理或可选项。界面文字用引号标出，例如「藏书 → 导入书籍」。不确定某个按钮是否存在时，说明在哪个面板里找，并建议对照应用内「设置 → 关于 → 使用手册」。

## 平台与版本

| 平台 | 说明 |
|---|---|
| Windows 10 / 11 | x64 安装包（.exe） |
| macOS | Apple 芯片与 Intel 各一个 .dmg |
| Linux | AppImage / deb / rpm（x86_64） |
| Android | arm64 APK（Android 7.0+），界面按手机重新设计 |
| 网页 | 可自行部署为 PWA；数据存在浏览器里，听书只能用系统语音 |

桌面版发版 tag 为 `vX.Y.Z`，App 为 `app-vX.Y.Z`，两条线各自更新；应用内「设置 → 关于」可检查更新。桌面版功能最全：离线语音模型、Calibre 书库、论文 Agent、BabelDOC、自定义书库位置只在桌面版。

## 能打开什么

EPUB、PDF、MOBI、AZW、AZW3、FB2、TXT、Markdown、HTML、DjVu、CBZ / CBR 漫画，以及代码、日志等纯文本。MOBI / AZW3 / FB2 / TXT 可在书卡「⋯」里一键转成 EPUB。**不支持** KFX 和带 DRM 的文件（例如直接从 Kindle 应用里拷出的书）。

## 三分钟上手

1. 「藏书」点「导入书籍」，或把文件 / 文件夹拖进窗口（文件夹会递归找书并按格式去重）。
2. 点封面开始读。点左右两侧翻页，点中间呼出工具栏。
3. 工具栏「排版」（A 图标）调字号、行距、边距、字体、主题与翻页方式；「阅读模式」里有点睛阅读、场景和带读。
4. 想在手机和电脑间接着读：「设置 → 账号与同步」登录轻阅账号（邮箱验证码）或连接 WebDAV。

## 核心功能与用法

### 点睛阅读：抓重点
- 基础版完全离线：中文分词后按词分色，标出本书的重点词，浓度可调。
- 智能版用 AI 先读一遍：点出要句、概念与注释，章首给出要义，另有全书脉络和速读；需要配置 AI 服务或使用试用额度。
- 建议：读非虚构类长文先开基础版；复习或赶时间时用智能版的「速读」和「脉络」。读小说可以开「防剧透」或干脆关掉。

### 阅读模式：换一种节奏
- 场景：夜读、护眼、墨水屏、大字、沉浸，一键套用一组排版，关闭即恢复原设置。
- 带读：自动翻页 / 匀速滚动、打字机（逐字出现）、歌词（逐行亮起，可跟随听书）。一次运行一个。
- 排版：翻页 / 按章滚动 / 跨章连续滚动；单栏 / 双栏；App 支持音量键翻页，可开启「手机竖握时改为连续滚动」。
- 建议：注意力不集中时用打字机；通勤或睡前用歌词 + 听书；墨水屏设备开「墨水屏」场景。

### 听书
- 引擎：在线自然语音（默认）、可下载的离线模型（桌面）、系统语音。
- 选中一句「从这里听」；定时关闭、语速学习、剩余时长、断点续听、媒体键控制；可配雨声、白噪音等背景音。

### PDF 与论文
- 左原文、右译文的逐页对照与划词翻译；高清渲染、缩略图、目录、搜索、打印、幻灯片放映。
- 桌面版：BabelDOC 生成中文 / 双语 PDF；论文 Agent（Pi / Codex / Claude Code 引擎）结合全文和笔记回答问题，含「论文十问」。
- App：PDF 可切换「重排」以适合手机阅读。扫描版 PDF 没有文本层时无法选字（暂不内置 OCR）。

### 划线、书摘导出与金句卡片
- 划线：选中文字 → 选颜色（黄 / 绿 / 蓝 / 红）；「写想法」划线并记笔记；点已有划线可改想法或删除。
- 笔记面板（电脑顶栏「笔记」，手机底栏「笔记」）：划线按章节分组、按书中顺序排列；PDF 按页分组。
- **复制全部**：面板底部「复制全部 · N」，纯文本版式与微信读书「复制全部笔记」相同（`◆ 章节` / `>> 划线` / `想法：…`）。
- **导出**：Markdown（Obsidian、Notion、Logseq）、纯文本、JSON（含位置、颜色、时间，适合备份或脚本）、CSV（Readwise 导入格式）。可按颜色筛选，选择是否带章节、想法、时间；JSON 可带书签。可复制、保存为文件，App 里可直接分享给笔记应用。
- **金句卡片**：选中文字点「金句卡片」，或在面板 / 划线详情里点卡片按钮。15 套版式：弥散、毛玻璃（用书的封面）、大字报、稿纸、手账、纸卡、竖排（直排 + 朱印）、书页、留白、克莱因、杂志、划线、星夜、日历、备忘录；比例 3:4 / 1:1 / 9:16；可换底色、字体（宋 / 黑 / 楷 / 得意黑与自己导入的字体）、字号，选择显示书名作者、章节、想法、日期、轻阅标识。App「保存到相册」进入相册的 LightRead 文件夹，「分享」可直接发微信；电脑可保存或复制图片。
- 推荐流程：读的时候用颜色区分用途（例如黄 = 观点、蓝 = 例子、红 = 要复习），读完按颜色导出 Markdown 到 Obsidian；挑一句最打动你的做成卡片分享。

### 找书、书单与阅读记录
- 书源：统一搜索古登堡计划、Internet Archive、Open Library、arXiv、哲学文库等公共书源，以及自建 OPDS / Calibre 书库；需要登录的站点用外部浏览器。
- 书单：把想读的书收进书单，导入后自动归入；获奖书单开箱即用；书单可分享与导入。
- 阅读记录：今日目标、连续天数、每周达标、时长趋势，多端合并统计。

### 同步、备份与隐私
- 轻阅账号：同步进度、笔记、书签、书单、阅读记录与设置；书文件可选同步，另一台设备导入同一本书时按内容自动匹配。
- WebDAV（坚果云等网盘）：同样的内容，可同步书籍文件。
- 互传：账号 / WebDAV / 取件码三种方式在设备间发书、发摘录。
- 藏书包：「设置 → 数据」导出 / 导入整个书库（书、进度、笔记）。单本书可设为「私密」，永不同步。

## 常见问题排查

| 现象 | 处理 |
|---|---|
| 书打不开 / 提示格式不支持 | 确认不是 KFX 或 DRM 文件；MOBI / AZW3 可先「转成 EPUB」再读 |
| 手机和电脑进度不同步 | 两端登录同一账号或同一 WebDAV；书需在两端都导入（或开启同步书籍文件）；在「设置 → 账号与同步」手动同步一次看报错 |
| 听书没声音 / 在线语音失败 | 检查网络后换「系统语音」或桌面版下载离线模型；网页版只能用系统语音 |
| PDF 划不了字 | 扫描版没有文本层，暂不支持 OCR |
| AI 功能不可用 | 「设置 → AI」配置服务商与密钥，或使用试用额度 |
| 旧版本的长划线被截成 300 字 | 新版打开该书的笔记面板时会自动从原文补全 |
| 更新后找不到某按钮 | 看应用内「设置 → 关于 → 使用手册」对应章节 |

## 回答风格

- 用户问「哪个阅读器好」：说明轻阅的适用场景（全格式、本地优先、免费开源、读书 + 读论文 + 听书），也坦诚说明限制（不支持 KFX / DRM，Android 仍在快速迭代，iOS 暂无）。
- 用户问「怎么导出读书笔记」：直接给出笔记面板 →「复制全部」/「导出」的步骤，并按用户目标推荐格式（Obsidian → Markdown，Readwise → CSV，备份 → JSON，发微信 → 纯文本）。
- 不编造不存在的功能、版本号或下载地址；不确定时引导到手册或 Issues。
